# Evidence-First Travel Planner

旅行の下調べは、事実が出所から切り離され、営業時間・予約・乗り換え・代替手段の条件を頭の中だけで確認したときに崩れます。このツールは、事実を出所につないだまま保持し、矛盾を説明できる所見に変える決定的なPythonのCLIです。

根拠のモデル化、鮮度の方針、タイムゾーンを考慮した制約の検証、公開しても差し支えない形への一般化、決定的なレポート、そして規則・CLI・スキーマ・全体という4つの水準のテストを示すものです。

技術文書の本体は英語の [README.md](README.md) です。この文書は要点だけをまとめたものですので、詳細はリンク先をご覧ください。

## 由来

交換留学中に、英国以外のヨーロッパの約15ヶ国について、自分で調べ、計画し、実際に旅行しました。繰り返していた手順は、公式の情報源と現地の情報源を見つけ、多言語の根拠を突き合わせ、出所を保ち、制約を日本語の行動手順に落とし、不確実な区間には代替案を残しておく、というものです。

**このソフトウェアは、その旅行の後に作りました。**当時の旅行を動かしていたものではありません。同梱している実行例は完全な架空のデータで、実在の旅程を再現したものでも、伏せ字にしたものでも、符号化したものでもありません。

## 動かしてみる

Python 3.9以降に対応しています。実行例はネットワークに接続しません。

```bash
python -m pip install -e .
evidence-travel demo --output-dir build/demo
```

同梱の[架空の旅程](src/evidence_travel/data/fictional_trip.json)には、妥当な判断と矛盾の両方を意図的に入れてあります。そのため終了コードは `2` になり、次の3つが出力されます。

- `build/demo/report.md` — 人が読むための説明
- `build/demo/report.html` — 依存のない、画面幅に応じたタイムライン
- `build/demo/summary.json` — 安定した機械可読の出力

終了コードはCLIの契約の一部です。所見がない場合が `0`、検証で所見が出た場合が `2`、入力が不正な場合が `3`、想定外の内部エラーが `4` です。

## 何を検証するのか

警告とエラーはいずれも、対象の実体、破られた制約、関係する根拠の識別子を名指しします。検査するのは、根拠の欠落と陳腐化、閉館日や営業時間からの逸脱、所要時間と最低乗り換え時間を満たさない移動、確定した予約どうしの重複、必要な予約の欠落、地理的な矛盾（申告された距離が大圏距離の下限を下回るなど）、代替手段のない脆い依存、そして情報源どうしの食い違いです。

**食い違いは平均して確からしさを作らず、見えるまま残します。**一覧と根拠は [What it validates](README.md#what-it-validates) の表にあります。

確からしさは `high`・`medium`・`low`・`unknown` の4段階です。根拠が支えられない小数の確率を、このツールは作り出しません。

## データモデルと構成

版を付けた [JSON Schema](schemas/itinerary.schema.json) が、活動・場所・営業時間・閉館日、根拠（参照またはURL、発行元、確認日時、鮮度の方針、検証状態、確からしさ）、予約と締切と取り消し条件、移動の時刻と所要時間と乗り換えの余裕と距離と手段、脆い依存とその代替行動と発動条件、そして突き合わせの対象になる事実を記述します。

中核のモデルと規則エンジンは決定的で、ネットワークに接続しません。地図や検索の連携は [`adapters.py`](src/evidence_travel/adapters.py) のプロトコルの背後に置きます。**提供元の結果は、時刻の付いた根拠として入る必要があり、人が確認した制約を黙って上書きすることはできません。**テストではAPIキーも有料サービスもアカウントもブラウザもネットワークも使わずに、これらを差し替えられます。区間と移動の定義は[アーキテクチャと規則の意味論](docs/architecture.md)にあります。

## 設計上の判断

- **標準ライブラリだけで動く中核** — 導入も同梱の実行例も小さく、ネットワークに接続しません
- **所見は不変で、並び順が決まっています** — レポートと自動処理の出力が安定します
- **説明はしますが、自動で直しません** — 食い違う情報源のどちらを採るか、予約を変えるかは人の判断です
- **直線距離は下限の検査です** — 実際の経路探索を提供するふりをせずに、不可能な申告を捕まえます
- **HTMLは静的な1ファイルです** — 公開されたダッシュボードより、確認と保存が容易です

## 個人情報の扱い

これは新しく作ったツールであって、実際の旅行記録を伏せ字にしたものではありません。架空の地名、合成した座標と時刻、作った情報源の記述、例示用に予約された定義域、そして新しく描いた図と文章だけが入っています。実際の予定・予約・切符・連絡・身分証・住所・詳細な位置履歴・金銭の記録・写真・非公開のリンク・非公開のリポジトリ履歴・第三者の文章は含んでいません。

## 制約

- 同梱の読み込み処理が検証するのは、実際に使う構造上の不変条件であって、JSON Schema のすべてのキーワードではありません
- 営業時間は、明示した閉館日を超える祝祭日の暦をモデル化していません
- 地理の規則は下限の妥当性検査であって、経路探索ではありません
- 提供元との連携はインターフェースだけで、特定の事業者向けの実装は同梱していません
- 食い違いの検出は事実のキーと値の一致によるもので、意味が同じかどうかは人が確認する必要があります
- このツールは矛盾を報告するだけで、予約・取り消し・購入・旅程の変更は行いません
